# Tech & Connectivity

## Reasoning

**Multi-country:** Hong Kong SAR (Sep 2–5) + Vietnam (Sep 5–13) — two jurisdictions, one phone. Dual-eSIM iPhone/Android preferred: install **Hong Kong eSIM** before departure, add **Vietnam eSIM** on landing HAN (Sep 5) without removing HK profile if data exhausted.

**Offline critical:** Grab (Vietnam), MTR/Octopus (HK), Google Maps offline packs, Vietnam e-visa PDF, hotel confirmations, tailoring receipts, customs shopping list, boarding passes.

**Power split:** Hong Kong **Type G** (UK three-pin, 220V) — US plugs **do not** fit. Vietnam **Type A/C** (220V) — US two-pin **often fits** without adapter. Pack one **universal adapter with Type G** for HK + Vietnam edge cases.

**Digital security:** Hong Kong SAR allows most Western apps (no mainland Great Firewall), but profile includes **China** shopping context — VPN useful for secure banking on hotel WiFi and if any mainland-side services are used. Vietnam: no VPN required; standard public-WiFi hygiene.

**Payment:** **Octopus** mandatory for frictionless HK MTR/minibuses; **Grab** primary in Vietnam (profile: avoid unregulated taxis); **Wise** multi-currency card for ATM + POS both countries.
