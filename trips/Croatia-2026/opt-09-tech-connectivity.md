# Tech & Connectivity

Stay map-and-message ready before you land so you can slow down and enjoy the walk.

### Connectivity setup

- ✅ Verify your phone is unlocked (or bring a compatible spare device).
- ✅ Plan eSIM/Mobile data for Croatia before arrival (or download an offline plan first).

### Offline plan

- ✅ Download offline maps for Dubrovnik + Split + Zadar and key day-trip routes.
- ✅ Save hotel addresses + transport links offline (notes app + screenshots).

### Tech setup checklist

| Item | Before departure | Offline backup |
|-------|--------------------|-----------------|
| Maps | Download city + coastline routes | Screenshot directions |
| Messaging | Confirm roaming plan/eSIM | WhatsApp + SMS fallback |
| Photos/docs | Export passport scans | Cloud + USB copy |
