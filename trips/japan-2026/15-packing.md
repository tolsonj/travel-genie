# Packing

## Reasoning

**Climate:** Hot-humid summer — lightweight breathable layers; one light rain jacket for afternoon storms. Temple visits need modest coverage (shoulders/knees optional but respectful).

**Activities:** Walking 15,000+ steps on Fushimi/Enoshima days — broken-in shoes critical. No formal wear needed except optional nice dinner in Gion.

**Luggage:** Carry-on only ideal for Shinkansen ease; checked bag OK if using takkyubin forwarding.

**Tech:** Type A plugs — US chargers work. Power bank essential for dawn-to-dusk days.
