# Tech & Connectivity

### Connectivity Strategy

#### Recommended: Japan eSIM (install before departure)

| Provider | Plan | Est. cost | Notes |
|----------|------|-----------|-------|
| **Airalo** | Japan 10–20 GB / 15–30 days | $18–28 | Easy QR; top up in app |
| **Ubigi** | Japan unlimited fair-use 15 days | $25–35 | Good for maps + photos |
| **Holafly** | Unlimited Japan 15 days | $35–45 | Higher cost; simple |

**Setup**

1. Phone must be **eSIM-compatible** (iPhone XS+, recent Pixel/Samsung).
2. Buy QR **before Jul 24**; install eSIM; set **Data Roaming ON** for eSIM line only.
3. Keep US physical SIM for SMS/2FA if needed; disable data on US line to avoid roaming.
4. **Tethering**: Check plan — useful for laptop on long train days.

#### Backup: Physical SIM / Pocket WiFi

- **Sakura Mobile / Japan Wireless** pocket WiFi — overkill solo; skip unless no eSIM phone.
- **Airport SIM** (NRT/HND): Bic Camera or vending — ¥3,000–5,000 for 10 GB if eSIM fails.

---

### VPN

**Not required for Japan.** Google, Gmail, Instagram, WhatsApp, Maps all work on local LTE.

Optional: privacy on hotel WiFi — any consumer VPN you already use is fine; **not** a pre-travel emergency like China.

### Essential Apps

| App | Purpose |
|-----|---------|
| **Google Maps** | Primary navigation; transit times; walking |
| **Japan Transit Planner** (Jorudan) or **Navitime** | Train exactness; platform numbers |
| **Google Translate** | Camera menu mode; download **Japanese offline** |
| **Visit Japan Web** | Immigration QR ([[03-immigration-entry]]) |
| **Suica / PASMO app** (iPhone Wallet) | IC card on phone — see below |
| **Tabelog** | Restaurant ratings (Japanese-heavy; use stars + photos) |
| **PayPay** | Optional; many shops — often need Japanese phone; **skip** unless local friend |
| **Booking.com / Rakuten** | Hotel confirmations offline |
| **Wise or bank app** | FX check; low-fee ATM if needed |

**Anime/gaming optional**: **Google Maps saved list** for Akihabara, Nipponbashi — no special app.

### Suica / PASMO / IC Card

| Step | Action |
|------|--------|
| **Day 1** | Add **Suica** to Apple Wallet (or buy physical at station machine) |
| **Load** | ¥3,000–5,000 initial; recharge at konbini/seven |
| **Use** | Tokyo Metro, JR locals, buses, konbini, some vending |
| **JR Pass days** | Jul 29–Aug 5 — pass for Shinkansen/Hida; IC for local buses/subways |
| **Return** | Balance refund at JR East service center before departure (small fee) |

**Note**: Regional cards interoperate — **ICOCA** in Kansai works like Suica.

**Physical vs digital**: Mobile Suica requires card in Wallet before trip; some US banks trigger fraud on top-up — load cash at station if needed.

### Offline Maps & Data Dead Zones

Download offline **before** leaving hotel WiFi:

| Region | Google Maps offline | Maps.me backup |
|--------|---------------------|----------------|
| Tokyo | Yes — 25 km radius Ueno + Kamakura | Optional |
| Takayama + Shirakawa-go | Yes — Takayama + Ogimachi | **Recommended** Alps trails |
| Kyoto | Central + Arashiyama | Optional |
| Osaka | Namba + KIX corridor | Optional |

**Alps**: Shirakawa-go village LTE spotty; offline map + screenshot bus times.

### Power & Plugs

| Item | Japan spec |
|------|------------|
| Plug | **Type A** — same as US flat pins |
| Voltage | 100V — US chargers labeled 100–240V OK |
| Adapter | **Not needed** for US plugs |
| Power bank | 20,000 mAh carry-on for long train/hike days |

---

### Digital Security (Solo)

| Risk | Mitigation |
|------|------------|
| Public WiFi | Prefer eSIM LTE; hotel WiFi OK for backups |
| 2FA lockout | Keep US number active for SMS codes |
| Document loss | iCloud/Google Drive copies of passport, JR Pass voucher, insurance |
| Banking | Notify bank of Japan dates; use **Wise/Charles Schwab**-style ATM if withdrawing |
| Theft | Phone leash in crowds (Fushimi, Dotonbori) |
