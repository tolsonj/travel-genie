# Contingency Plans

## Reasoning

**Single country reduces complexity:** No visa-denied border crossings between countries. Primary risks: heat/typhoon weather, missed ICN connection, Shinkansen delay, illness during peak summer.

**Key contacts:** US Embassy Tokyo, airline rebooking lines, hotel direct numbers, insurance 24h hotline.

## Output

### 1. Weather ruins outdoor day

| Scenario | Action |
|----------|--------|
| Typhoon/rain Aug 2 (Senso-ji) | Swap to **teamLab Planets** (indoor) + **Tokyo National Museum** |
| Rain Aug 3 (Enoshima) | **Shimokitazawa** vintage + **Tokyo Midtown** / **Ginza Six** indoor |
| Rain Aug 5 (Fushimi/Kinkakuji) | **Nijo Castle** interior + **Kyoto International Manga Museum** |
| Rain Aug 6 (Arashiyama) | **Nishiki Market** extended + **Kyoto Railway Museum** |
| App | Japan Meteorological Agency; check typhoon track T-24h |

### 2. Missed flight / connection

| Scenario | Action |
|----------|--------|
| Miss ATL departure Jul 31 | Call Delta **1-800-221-1212** immediately; rebook next available; hotels flexible if notified |
| Miss ICN connection Aug 7 | Korean Air desk at ICN **+82-2-2656-2001**; separate tickets — no protection; insurance claim |
| Miss KIX check-in | Haruka + security need 90 min; if late, call Korean Air rebooking |

### 3. Sick during trip

| Scenario | Action |
|----------|--------|
| Mild illness | Rest at hotel; konbini electrolytes; pharmacy (matsukiyo) for OTC |
| Need doctor | Hotel front desk calls taxi to clinic; or **119** ambulance if emergency |
| Cannot do dawn activity | Skip Fushimi summit; do Nijo Castle interior instead |
| Insurance | Call 24h hotline before non-emergency ER visit |

### 4. Visa / entry denied

| Scenario | Action |
|----------|--------|
| Denied at HND (rare) | US Embassy **+81-3-3224-5000**; airline returns you on same carrier |
| Backup | Show return ticket KIX→ATL, hotel bookings, funds |

### 5. Lost passport

| Step | Action |
|------|--------|
| 1 | File police report at nearest koban (police box) — get report number |
| 2 | Contact US Embassy Tokyo **+81-3-3224-5000** (emergency after-hours **+81-3-3224-5000**) |
| 3 | Bring police report, passport photo, ID copy, travel itinerary |
| 4 | Emergency passport issued — allow 1–3 business days |
| 5 | Rebook KIX→ATL if passport not ready by Aug 7 |

### 6. Political unrest / travel ban

| Scenario | Action |
|----------|--------|
| US State Dept Level 3–4 advisory | Check [travel.state.gov](https://travel.state.gov); contact airline for waiver |
| Natural disaster (earthquake) | Follow hotel evacuation; US Embassy **STEP** enrollment alerts |
| Japan risk | Low — earthquake protocol: drop-cover-hold; know hotel exits |

### 7. Solo traveler wants to change plans

| Scenario | Action |
|----------|--------|
| Skip Kyoto | Not recommended — hotels booked; minimum enjoy Nishiki + one temple |
| Extend Tokyo | Requires rebooking KIX flight + Kyoto hotel cancel — expensive |
| Add Osaka day trip | Skip — violates relaxed pace |

### 8. Budget overrun

### 9. Lost luggage

| Step | Action |
|------|--------|
| 1 | File PIR at airport baggage office before leaving |
| 2 | Photograph form; get reference number |
| 3 | Buy essentials — keep receipts for insurance |
| 4 | Uniqlo GU for replacement clothes (~¥2,000/item) |
| 5 | Delivery to hotel via takkyubin when found |

### 10. Strike / natural disaster closes transport

| Scenario | Action |

| Haruka suspended | Highway bus KIX (~¥2,500); allow +60 min |
| All KIX flights cancelled | Hotel near airport (KIX Sheraton); rebook via airline app |
