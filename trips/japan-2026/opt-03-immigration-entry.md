# Immigration & Entry

### Country entry checklist — Japan

| Requirement | Detail |
|-------------|--------|
| Visa | **Not required** — US citizens, tourism ≤90 days |
| Stay limit | 90 days |
| Processing | N/A — stamp on arrival |
| Cost | Free |
| Documents | Valid passport; return/onward ticket; proof of funds (rarely asked) |
| Visit Japan Web | Register at [vjw-lp.digital.go.jp](https://vjw-lp.digital.go.jp) — QR for immigration + customs |
| Landing card | Replaced by VJW QR when registered |

### Travel authorizations (2026)

| System | Applies? | Action |
|--------|----------|--------|
| ETIAS (EU) | No | — |
| UK ETA | No | — |
| Japan VJW | **Yes** | Complete 3 days before arrival |
| US ESTA | N/A (US citizen) | — |
| Transit visa (ICN layover) | **No** — Korean Air + Delta connection at ICN stays airside if same ticket |

### Passport validity rules

| Rule | Japan |
|------|-------|
| Minimum validity | Duration of stay (recommend 6+ months) |
| Blank pages | 1+ for entry stamp |
| Dual citizenship | Enter/exit on same passport; use US passport throughout |

### Vaccination & health declarations

| Item | Status |
|------|--------|
| Yellow fever | Not required from US |
| Routine vaccines | Hep A, tetanus — standard travel health |
| COVID | No entry test/vaccine mandate (verify T-30 days) |
| Health declaration | Via Visit Japan Web if prompted |

### Reciprocal restrictions

| Check | Result |
|-------|--------|
| US travel bans affecting Japan entry | None |
| Japan entry restrictions on US citizens | None for tourism |

### Application timeline

| When | Action |
|------|--------|
| Now | Confirm passport expiry ≥ Feb 2027 |
| T-90 days | Book flights (open-jaw) |
| T-30 days | Complete Visit Japan Web registration |
| T-14 days | Print/save VJW QR + hotel confirmations offline |
| Arrival HND Aug 1 | Immigration → customs → activate IC card |
| Departure KIX Aug 7 | Tax-free shopping receipts if applicable |

### Red flags

| Flag | Mitigation |
|------|------------|
| Separate one-way tickets (no connection protection) | Allow 3+ hr layover at ICN; consider travel insurance with missed-connection cover |
| Medication import | Declare prescription meds; carry doctor's note in English |
| Working remotely | Tourist entry does not permit paid work — meetings OK, employment not |

### Backup plan if entry denied

| Scenario | Action |
|----------|--------|
| Immigration questions | Show return ticket KIX→ATL Aug 7, hotel bookings, VJW QR |
| Visa overstay risk | Not applicable — 6 nights well within 90 days |
| Denied entry (rare) | Contact US Embassy Tokyo +1-301-985-8840 (after hours); rebook via airline |
