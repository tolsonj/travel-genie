# Packing

| # | Item |
|---|------|
| 1 | Passport + VJW QR screenshot |
| 2 | Phone + USB-C/Lightning cables |
| 3 | 20,000 mAh power bank |
| 4 | Credit card + backup card |
| 5 | Comfortable walking shoes (broken in) |
| 6 | Lightweight breathable shirts ×4 |
| 7 | Lightweight pants/shorts ×2 + 1 modest long pant for temples |
| 8 | Sun hat + SPF 50 + sunglasses |
| 9 | Light packable rain jacket |
| 10 | Small daypack (20L) |
| 11 | Reusable water bottle |
| 12 | Travel insurance card |
| 13 | Prescription meds in original containers |
| 14 | Electrolyte packets |
| 15 | Blister kit (moleskin, bandages) |

### Japan-specific gear

| Item | Why |
|------|-----|
| Hand towel / tenugui | Some restrooms lack paper towels |
| Coin purse | Japan is coin-heavy despite cards |
| Modest scarf/shawl | Temple visits, AC blast |
| Umbrella (compact) | Afternoon thunderstorms |
| Cooling towel | August heat management |

### Transit day bag (Jul 31, Aug 4, Aug 7)

| Item | Location |
|------|----------|
| Passport + boarding passes | Personal item — always on body |
| Snacks (US departure) | Carry-on |
| Entertainment (downloaded) | Phone/tablet |
| Charger + power bank | Personal item |
| Change of shirt | Carry-on |
| Japan guide PDF / offline maps | Phone |
| Pen (for customs forms) | Personal item |

### Tech / battery survival

| Day | Strategy |
|-----|----------|
| Long-haul flights | Full charge + power bank; aisle for bathroom walks |
| Dawn days (Fushimi, Arashiyama) | 100% charge; power bank; low-power mode after photos |
| Enoshima | Waterproof phone pouch optional |
