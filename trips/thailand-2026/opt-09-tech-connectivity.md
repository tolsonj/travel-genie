# Tech & Connectivity

### Connectivity strategy

| Option | Provider | Data | Cost est. | Notes |
|--------|----------|------|----------:|-------|
| **Recommended** | **Airalo** Thailand eSIM | 10 GB / 15 days | ~$15 | Install before departure |
| Alt | **Holafly** unlimited TH | 7 days | ~$25 | Hotspot OK |
| Backup | AIS tourist SIM at BKK | 8 GB | ~THB 599 | Airport kiosk |

### Pre-departure offline kit

| Item | Action |
|------|--------|
| Google Maps | Download Bangkok, Chiang Mai, Ao Nang offline |
| Grab app | Install + add payment before arrival |
| Google Translate | Download **Thai** offline pack |
| Boarding passes | Wallet app + screenshot |
| Hotel PDFs | Files app + email |
| TDAC confirmation | Screenshot QR |
| Insurance card | Photo + PDF |

### Power & plugs

| Topic | Detail |
|-------|--------|
| Plug types | A / B / C (220V) — US plugs often fit |
| Adapter | Universal adapter recommended |
| Voltage | 220V — phone/laptop OK; check hair tools |
| Portable charger | 10,000 mAh for long transit days |

### Digital security

| Topic | Guidance |
|-------|----------|
| VPN | Optional — not required in Thailand |
| Public WiFi | Avoid banking on airport/hotel open WiFi |
| Document backup | Encrypted cloud + email to self |

### Payment apps

| App | Works in Thailand? |
|-----|-------------------|
| Grab | **Yes** — primary transport |
| Apple Pay / Google Pay | Limited — card in Grab |
| Wise card | **Yes** — ATM + POS |
| LINE Pay | Local — optional |

### Tech setup checklist

- [ ] eSIM purchased and installed
- [ ] Grab account + Visa linked
- [ ] Offline maps downloaded (3 cities)
- [ ] Thai translation pack offline
- [ ] Universal adapter packed
- [ ] 10,000 mAh power bank charged
- [ ] Boarding passes offline
- [ ] TDAC completed T-72h (if required)
