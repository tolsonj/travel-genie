# Immigration and Entry

### Country-by-country entry checklist

#### Thailand (arrival ~2026-08-01 at BKK)

| Item | Requirement |
|------|-------------|
| Visa | **Not required** — US passport **visa exemption** up to **60 days** (tourism, 2026) |
| Passport validity | **6+ months** beyond entry (through **Feb 2027** minimum) |
| Blank pages | ≥1 recommended |
| Arrival card | **TDAC** online or kiosk at airport (verify 2026 process) |
| Funds proof | Rarely asked; have ~THB 20,000 equivalent or hotel + return ticket |
| Onward ticket | **Required** — KBV→ATL Aug 8 confirmation |
| Customs | Standard; declare currency >USD 15,000 equivalent |

**Portal:** [Thailand Immigration](https://www.immigration.go.th/) · [TDAC](https://tdac.immigration.go.th/) (verify active)

### Travel authorizations (2026)

| System | Applies? | Action |
|--------|----------|--------|
| US ESTA | N/A | — |
| Thailand visa | **No** (visa exemption) | — |
| TDAC digital arrival | **Likely yes** | Complete online within 72h of arrival |
| UK ETA / ETIAS | No | — |

### Application timeline

| When | Action | Owner |
|------|--------|-------|
| **T-90 days** (~May 2026) | Book ATL→BKK + KBV→ATL open-jaw | Traveler |
| **T-60 days** | Book domestic BKK→CNX, CNX→KBV | Traveler |
| **T-30 days** | Confirm TDAC requirement; re-check visa exemption duration | Traveler |
| **T-14 days** | Print hotel confirmations, onward ticket, insurance | Traveler |
| **T-72h before BKK arrival** | Submit TDAC if mandatory | Traveler |
| **Day of arrival** | Passport + TDAC QR + customs declaration if >allowance | Traveler |

### Documents to carry (border packet)

1. Passport (6+ mo validity)
2. TDAC confirmation QR (if required)
3. Flight confirmations: ATL→BKK, BKK→CNX, CNX→KBV, KBV→ATL
4. Hotel confirmations: Bangkok Aug 1–4, Chiang Mai Aug 4–6, Krabi Aug 6–8
5. Travel insurance certificate
6. US Embassy Bangkok emergency card

### Red flags

| Risk | Severity | Mitigation |
|------|----------|------------|
| Passport <6 months validity | **High** | Renew before booking |
| Overstay (60-day limit) | **High** | Trip is 8 days — no issue |
| No onward ticket | **Medium** | Print KBV→ATL confirmation |
| Restricted medications (opioids, ADHD without script) | **Medium** | Carry doctor letter + original Rx |
| Third-party visa scam sites | **Low** | Not needed — visa exempt |

### Backup plan if entry denied

1. **Entry refused (rare):** Return on next available flight; invoke travel insurance; contact US Embassy Bangkok +66 2 205 4000.
2. **TDAC system down:** Paper form at airport (legacy TM6 if still offered).
3. **Passport lost in Thailand:** US Embassy Bangkok emergency passport; police report required.
