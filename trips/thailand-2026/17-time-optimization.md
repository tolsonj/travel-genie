# Time Optimization

## Reasoning

**PTO:** 7 hub nights ≈ 5–6 PTO days if Fri depart / Sat return — Aug 1 is Saturday arrival (good).

**Date-flex:** MCP unavailable — desk estimate ±2 days on ATL↔Asia long-hauls only.

**70% rule:** Soft days Aug 1, Aug 4; anchor activity each exploration day.
