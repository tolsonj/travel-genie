# Customs & Borders

## Reasoning

**Single country:** No international border crossings mid-trip. Customs events: (1) US departure, (2) Thailand arrival BKK Aug 1, (3) Thailand departure KBV Aug 8, (4) US arrival.

**Domestic flights:** BKK–CNX–KBV — no customs; standard security only.

**Purchasing:** Bangkok best for luxury/shopping; carry receipts for US re-entry.

## Output

### Trip customs overview

| Event | Location | Type | Key action |
|-------|----------|------|------------|
| Arrival | BKK Aug 1 | Thailand immigration + customs | TDAC; declare cash >$15K |
| Domestic | BKK, CNX, KBV airports | Security only | Liquids <100ml |
| Departure | KBV Aug 8 | Thailand exit + VAT refund | PP10 stamp if claiming |
| US arrival | ATL | CBP | Declare goods >$800 |

### Thailand arrival customs

| Allowance | Limit |
|-----------|-------|
| Personal effects | Duty-free for tourist |
| Alcohol | 1L spirits + wine limits (verify current) |
| Cigarettes | 200 sticks |
| Currency declare | >USD 15,000 equivalent |

### Restricted items (Thailand)

| Item | Rule |
|------|------|
| E-cigarettes | **Banned** — do not import |
| Buddha images (large) | Export restrictions for antiques |
| Ivory / wildlife products | **Prohibited** |
| Medications | Opiods/ADHD need Rx + letter |

### US re-entry (ATL)

| Allowance | Limit |
|-----------|-------|
| Duty-free goods | $800 personal exemption |
| Alcohol | 1L spirits (21+) |
| Agricultural | **Declare** all food/plant items — many Thai items restricted |
| Gifts | Combined $800 |

### VAT refund (Thailand)

| Step | Action |
|------|--------|
| 1 | Shop at VAT-refund participating stores (PP10 form) |
| 2 | Min 2,000 THB/shop, 5,000 THB total |
| 3 | Show goods + passport at KBV airport refund desk (if counter open) |
| 4 | Refund to credit card or cash minus fee |

### Purchasing strategy

| Buy in | Category | Why |
|--------|----------|-----|
| Bangkok | Clothing, sneakers, mall goods | Best selection + VAT refund |
| Chiang Mai | Crafts, textiles | Quality + price |
| Krabi | Minimal | Avoid carrying bulk before flight home |

## Validation

| Check | Result |
|-------|--------|
| Each border crossing documented? | **Pass** — arrival/departure only |
| Restricted items covered? | **Pass** |
