# Route Optimization

### Visual route summary

```
ATL ──(Jul 31)──► BKK ──(Aug 4)──► CNX ──(Aug 6)──► KBV ──(Aug 8)──► ATL
         │              │                │                │
    Travel day      Bangkok          Chiang Mai          Krabi
```
