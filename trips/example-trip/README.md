# example-trip

Fictional demo trip for the public repository. All names, airports, budgets, and dates are placeholders.

Copy this folder when starting a real plan:

```bash
cp -R trips/example-trip trips/your-slug-2026
```

Then edit `profile.md` and run the CoT workflow. Personal trip folders under `trips/` are gitignored by default (see repo-root `.gitignore`).
