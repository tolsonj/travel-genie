# Immigration & Entry

### Country Entry Checklist — 🇲🇽 Mexico

| Requirement | Details |
|-------------|---------|
| Visa | **None** — US citizens visa-exempt for tourism up to **180 days** |
| Passport validity | Valid for duration of stay; **6 months beyond Aug 13, 2026** recommended (i.e., valid through **Feb 13, 2027** minimum) |
| Blank pages | **1 page** minimum per traveler (entry stamp + FMM) |
| Entry document | **FMM (tourist card)** — issued at immigration or via airline check-in app |
| Entry port | **SJD** — Los Cabos International (San José del Cabo) |
| Duration | Up to 180 days (trip: 7 days) |
| Proof of departure | Return ATL tickets (**BOOKED**) |
| Minors | Denver & Kennedy — both parents present; carry birth certificates as backup |

### FMM / Tourist Card (2026)

| Method | Details |
|--------|---------|
| **Electronic FMM** | Pre-arrival via Mexican immigration portal or airline app; QR code at SJD |
| **Paper FMM** | Issued at counter if e-FMM unavailable — keep stub until departure |
| Cost | Included in airline ticket or ~$30 USD if purchased separately |
| Retention | **Do not lose** — required to exit Mexico |

### Health Requirements

| Requirement | Status |
|-------------|--------|
| Mandatory vaccinations | **None** for US → Mexico tourism |
| COVID-19 | No test/vaccine required (2026) |
| CDC recommended (optional) | Hepatitis A, typhoid, routine vaccines current |
| Travel insurance | Recommended — not required for entry |
| Sun/heat | Primary health risk in August — hydration, SPF 50+, limit midday exposure |

### Red Flag Warnings

🚨 **Do not lose FMM stub** — exit denied or fine without it.

🚨 **6-month passport rule** — airlines may deny boarding if expiry within 6 months of return.

🚨 **Customs declaration** — declare food, plants, >$10,000 USD equivalent.

| Scenario | Action |
|----------|--------|
| FMM system down at SJD | Request paper form; allow +30 min |

| Secondary inspection | Show Inspirato booking, return tickets, tourism purpose |
