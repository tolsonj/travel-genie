# Customs & Borders

### Entry — Mexico (Aug 7)

| Step | Action |
|------|--------|
| Documents | Passport valid 6+ months · print hotel/Inspirato address |
| Tourist permit | Complete **FMM** (Forma Migratoria Múltiple) — keep stub for exit |
| Customs declaration | Nothing to declare if no commercial goods |
| Secondary inspection | Rare for family tourists — remain polite, answer briefly |
| Ground transport | Proceed to baggage → rental pickup or shuttle |

### Exit — Mexico (Aug 13)

| Step | Action |
|------|--------|
| Airport arrival | **3 hours** before international departure |
| FMM surrender | Return tourist permit stub at immigration |
| Carry-on liquids | Standard TSA 3-1-1 if pre-clearance not available |

### Duty-free — Mexico departure (SJD)

| Item | Allowance / note |
|------|------------------|
| Tequila/mezcal | Buy **after** security if flying to US — check airline liquid rules for connections |
| Local crafts | Keep receipts for US CBP |
| Perfume/alcohol shop | 1L spirit typical international allowance — verify current CBP |

### Returning home — US CBP (ATL)

| Topic | Rule |
|-------|------|
| Duty-free allowance | **$800** per person · **$3,200** family of 4 if traveling together |
| Gifts | Declare items over allowance — honesty avoids penalties |
| Tequila/mezcal | 1 liter per adult duty-free (21+) — excess taxed |
| Fresh produce/meats | **Prohibited** |
| Cuban cigars | Standard US restrictions apply |
| Art/crafts | Declare value; receipts help |

### Medications & health items

| Item | Guidance |
|------|----------|
| Prescription meds | Original pharmacy labels · quantity for trip duration |
| Controlled substances | Doctor letter + prescription copy |
| OTC | Standard travel kit OK |
| Sunscreen/aerosols | Checked bag if over 100ml |

### Prohibited / restricted (common mistakes)

| Item | Verdict |
|------|---------|
| Fresh cheese/fruits | **Do not bring back** |
| Protected coral/shells | **Prohibited** |
| Firearms/ammo | **Prohibited** without license |
| Excess cash | Declare **$10,000+** USD equivalent combined |
