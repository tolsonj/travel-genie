# Packing

### 1. Do not forget — core list (15 items)

| # | Item | Why |
|---|------|-----|
| 1 | Passports (×4) + copies | Mexico entry; offline backup |
| 2 | Travel insurance card + policy PDF | Health, hurricane, activity coverage |
| 3 | Flight + Inspirato confirmations (offline) | Gate codes, shuttle, check-in |
| 4 | SPF 50+ sunscreen (large + travel size) | August UV — reapply constantly |
| 5 | Wide-brim hats (×4) | Heat deal-breaker mitigation |
| 6 | Polarized sunglasses (×4) | Water, golf, desert glare |
| 7 | Refillable water bottles (×4) | Hydration protocol — 3–4 L/day target |
| 8 | Electrolyte packets | Post-golf, hike, boat |
| 9 | US credit/debit cards (no FTF preferred) | Resorts, restaurants, Uber |
| 10 | Small USD cash (~$200) | Tips, markets, backup |
| 11 | Phone + chargers | Maps, Uber, Inspirato app |
| 12 | Prescription meds (7+3 days) | Full trip + delay buffer |
| 13 | One nice outfit per adult (birthday dinner) | Flora's / Edith's Aug 11 |
| 14 | Rash guards / UPF swim shirts (daughters) | Snorkel + all-day sun |
| 15 | Printed emergency card | From [[14-health-safety]] |

### 2. Beach / resort / golf gear — Los Cabos August

| Category | Items | Notes |
|----------|-------|-------|
| **Beach / pool** | Swimsuits (×2 each), cover-ups, flip-flops, beach bag, dry bag for boat | Pool block 11 AM–3 PM daily |
| **Resort / dinners** | Linen shirts, sundresses, casual sandals, one dressy-casual set | San José galleries Aug 8; birthday Aug 11 |
| **Golf (Jack + optional family)** | Golf shoes, gloves, hat with neck cover, collared shirts, shorts/skorts, balls/tees (or rent) | Dawn tee; cart recommended in heat |
| **Nature / hike** | Hiking shoes or sturdy sneakers, light long pants option, small daypack | Mt Solmar, desert — Aug 10 |
| **Snorkel (if Cabo Pulmo wins vote)** | Mask/snorkel (personal fit) or confirm operator provides | Rash guard mandatory |
| **Spa (Aug 11)** | Flip-flops, minimal jewelry | Resort spa or Spa Baja |
| **Sun extras** | Aloe gel, lip SPF, UPF 50+ long-sleeve (optional golf/boat) | After-sun for daughters |

### 3. Day bag — excursions (Arch, Todos Santos, Cabo Pulmo)

| Item | Purpose |
|------|---------|
| Crossbody or small backpack | Hands free at marina |
| Water bottles (filled) | Heat protocol |
| Snacks (granola, fruit) | Long drives; border-style delays N/A but boat/hike hunger |
| Sunscreen + hat | Reapply on water |
| Light layer (thin shirt) | AC restaurant → hot marina |
| Phone + portable charger | Maps, photos |
| Cash (small pesos/USD) | Tips, market |
| Dramamine (if seasick-prone) | Arch boat, sail |
| Copy of passport | Leave original in safe |

### 4. Tech & battery survival

| Item | Notes |
|------|-------|
| Phones (×4) | Uber, Inspirato, weather alerts |
| Chargers + 1 multi-port USB brick | Shared family charging |
| Portable battery (10k+ mAh) | Long excursion days |
| US plugs — **no adapter needed** | Mexico Type A/B same as US |
| Download offline maps (Google Maps) | San José, Cabo, corridor |
| eSIM / roaming | Per [[09-tech-connectivity]] when finalized |
| Waterproof phone pouch | Boat / pool |

| Item | Qty / note |
|------|------------|
| Ibuprofen / acetaminophen | Headache, heat |
| Antihistamine | Stings, allergies |
| Anti-diarrheal + rehydration salts | Stomach upset |
| Bandages, blister pads | Hike, golf, sand |
| Insect repellent (light) | Evening outdoor |
| Hand sanitizer | Markets, street food |
| Tweezers | Cactus, splinters |
| Prescription meds | Labeled, carry-on |

| Section | Contents |

### 7. Luggage strategy (4 travelers)

| Bag | Owner | Contents |
|-----|-------|----------|
| Checked (×2–4) | Family | Clothes, golf shoes, sunscreen bulk, shared toiletries |
| Carry-on (×4) | Each person | 1-day outfit, meds, electronics, valuables |
| Personal item | Jack or Audrey | Document folder, chargers, snacks |

**Tequila/mezcal purchases (Aug 12):** Checked luggage only; declare at US customs; wrap in clothing.
