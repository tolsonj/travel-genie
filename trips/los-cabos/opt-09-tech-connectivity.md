# Tech & Connectivity

### Connectivity strategy — Mexico eSIM

| Option | Provider | Data | Cost est. | Notes |
|--------|----------|------|----------:|-------|
| **Recommended** | **Airalo** Mexico | 5 GB / 7d | ~$9–12 | Install before ATL departure |
| Alt | **Holafly** Mexico unlimited | 7d | ~$25–30 | Hotspot for kids' iPads |
| Alt | **Nomad** Mexico | 10 GB / 15d | ~$12–18 | Buffer if trip extends |
| Backup | **Telcel** tourist SIM at SJD | 5–8 GB | ~$15–25 USD | Physical if eSIM fails |

**Party of 4:** Budget ~$40–50 total if each adult phone gets eSIM; kids can hotspot from one profile.

### Pre-departure offline kit

| Item | Action |
|------|--------|
| Google Maps | Download offline: **San José del Cabo**, **Cabo San Lucas**, **Corridor** |
| Uber | Install + link Visa · test login before trip |
| Inspirato itinerary | PDF gate codes, address, WiFi password |
| Restaurant confirmations | Metate · Los Deseos screenshots |
| Golf tee times | Email PDF Aug 9 |
| Boarding passes | Wallet + email backup |
| Translate | Spanish offline pack |

### Power & plugs

| Topic | Mexico (Los Cabos) |
|-------|---------------------|
| Plug type | **Type A / B** — same as US |
| Voltage | 127V (most US devices OK) |
| Adapter needed | **No** for US plugs |
| Portable charger | 10,000 mAh — long beach/golf days |

### Digital security

| Topic | Guidance |
|-------|----------|
| VPN | **Not required** — Google/Maps/Uber work normally |
| Public WiFi | Avoid banking on marina open networks |
| Document backup | Encrypted cloud + email PDFs |

### Payment apps

| App | Los Cabos | Notes |
|-----|-----------|-------|
| **Uber** | **Yes** | Marina · San José · Corridor — surge at cruise days |
| Apple Pay / Google Pay | Growing | Not universal — carry physical card |
| Venmo/Zelle | US-only | Use for tipping US friends only |
| Credit cards | Visa/MC widely | Notify travel dates |

### Tech setup checklist

- [ ] eSIM installed + data tested
- [ ] Uber account payment valid
- [ ] Offline maps downloaded
- [ ] Inspirato access link saved offline
- [ ] 2FA backup codes (SMS may lag on eSIM)
- [ ] Share location with family at home (optional)
