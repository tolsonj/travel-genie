### Customs cheat sheet (US return via ATL)

| Item | Rule |
|------|------|
| Personal allowance | **$800**/person duty-free |
| Crafts / art | Declare if over allowance; keep receipts |
| Tequila/mezcal | Checked luggage · duty applies above allowance |
| Fresh food/plants | **Prohibited** — no untreated agricultural souvenirs |
